## Reportar uma Vulnerabilidade

Este projeto é 100% client-side (sem backend, sem servidor, sem banco de dados externo).

Todos os dados ficam no `localStorage` do seu próprio navegador — **nenhum dado é enviado para a internet**.

Se mesmo assim encontrar algum problema de segurança (ex: XSS no criador de missões), por favor:

1. **NÃO abra uma Issue pública**
2. Envie um e-mail para: **agapeagma@gmail.com**
3. Use o assunto: `[SECURITY] LIFE OS Pixel Realms`

Responderemos em até **48 horas**.
